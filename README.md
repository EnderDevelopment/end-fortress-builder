# End Fortress

End Fortress is a Minecraft plugin that instantly builds a futuristic blue-black castle in the End dimension. Featuring a towering central keep, four corner towers, glowing neon trim, and a majestic entrance, this plugin transforms the void into a stunning high-tech fortress. Whether you're looking for an impressive base, a dramatic arena, or merely a breathtaking build, End Fortress delivers with sleek aesthetics and interactive decorations.

## Install

1. Download the `EndCastle.jar` file from the latest release.
2. Place the JAR file into your server's `plugins/` folder.
3. Restart your server or run `/reload confirm` (if supported by your server software).
4. Verify the plugin loaded by checking the console for "FuturisticEndCastle enabled".

## Use

1. Navigate to the End dimension (`/execute in minecraft:the_end run tp @s ~ ~ ~`) or travel there manually.
2. Stand in a location where you want the fortress to be built.
3. Run `/endcastle` (or use aliases `/neoncastle` or `/castle`) to generate the full structure.
4. Run `/endcastledecor` to add decorative elements: neon beacons, end rods, glowing runes, and a fireworks show.
5. Explore your new fortress! The central keep features a glowing light column, blue glass windows, and a neon-trimmed entrance. Four corner towers and mid-towers complete the defensive layout.
6. Use `/endcastledecor` again anytime to refresh effects or trigger another firework display.

The construction is instant and doesn't require any special permissions — any player can run the commands by default. Note that bedrock blocks are protected and won't be overwritten.
